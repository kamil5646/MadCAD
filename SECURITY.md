# Security Policy

## Supported version

Poprawki bezpieczeństwa otrzymuje najnowsza stabilna wersja MadCAD. Użytkownicy powinni aktualizować aplikację wyłącznie z oficjalnych wydań GitHub i weryfikować podpis systemowy oraz opublikowaną sumę SHA-256.

## Reporting a vulnerability

Nie publikuj podatności w zwykłym issue. Użyj prywatnego formularza **Security → Report a vulnerability** w repozytorium GitHub. Jeśli formularz jest niedostępny, napisz na `kkasprzak15@icloud.com` z tematem `MadCAD security`.

W zgłoszeniu podaj wersję, system, kroki odtworzenia, wpływ i — jeśli to możliwe — bezpieczny proof of concept. Nie dołączaj cudzych danych ani sekretów. Odbiór zgłoszenia powinien zostać potwierdzony w ciągu 7 dni.
