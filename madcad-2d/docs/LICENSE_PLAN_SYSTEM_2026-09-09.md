# System planów licencyjnych — 2026-09-09

MadCAD rozdziela trzy czytelne stany: osobisty, 40-dniowa ocena komercyjna i komercyjny potwierdzony dokumentem zakupu. Wybór i początek oceny są zapisywane lokalnie, bez konta, klucza, odcisku urządzenia i wysyłania danych.

Koncepcja nawiązuje do rozdzielenia Autodesk Fusion for Personal Use, bezpłatnej próby i płatnej subskrypcji, ale zachowuje własne warunki MadCAD: pełna funkcjonalność pozostaje dostępna prywatnie, a licencja komercyjna jest bezterminowa dla zakupionej głównej wersji.

Interfejs nie twierdzi, że lokalny wybór jest dowodem zakupu. Wiążącym dowodem pozostaje faktura lub pisemne potwierdzenie zgodnie z plikiem `LICENSE`.

Statusu komercyjnego nie można nadać przypadkowym pojedynczym kliknięciem. Użytkownik podaje nazwę licencjobiorcy oraz numer faktury lub pisemnego potwierdzenia; dane są przechowywane tylko lokalnie i są widoczne w opisie aktywnego planu. Aplikacja nie wysyła ich do serwera i nie udaje, że lokalny wpis weryfikuje zakup.
